# 📊 Vrinda Store Annual Report 2022

> Real-World Data Analysis Project | Excel Dashboard

![Dashboard](Dashboard/dashboard_screenshot.png)

## 📌 Project Overview
Annual sales analysis of Vrinda Store using raw transactional data of 10,000+ orders across multiple platforms and Indian states.

## ❓ Business Questions Answered
- Which month had the highest orders and sales?
- How do monthly sales compare to order volume throughout the year?
- Who buys more — Men or Women?
- Which order statuses exist and what percentage were delivered?
- Which are the Top 5 states by total sales?
- Which sales platform (Amazon, Flipkart, Myntra etc.) contributes most?

## 📈 Key Insights
- 📅 Peak Month: March had highest sales (~₹1.93M) and order count
- 👩 Women dominate purchases: 64% vs Men 36%
- 📦 92% orders successfully delivered
- 🗺️ Top State: Maharashtra (₹2.99M in sales)
- 🛒 Amazon leads all platforms with 35% of total orders
- 👥 Adult women are the highest buying segment across all age groups

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Combo Charts
- Data Cleaning
- Interactive Slicers
